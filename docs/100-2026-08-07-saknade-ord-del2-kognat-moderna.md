## Metod

1. **Källor:** Finetuning-data (254 SFT-par), false-friends-ordlista (100 poster),
   moderna IT-termer (192 poster)
2. **Referensordlistor:**
   - CS IT-ordlista (14 810 ord, från Computer Sweden)
   - Svensk frekvensordlista (50 000 ord, FrequencyWords 2018)
   - **SAOL** (Svenska Akademiens ordlista, 2026-upplagan) — uppslaget
     via svenska.se med automatiserad Safari-navigering
3. **Kriterium:** Ord som saknas i *både* CS och frekvensordlistan tas med i
   rapporten. SAOL-status anges separat per ord.
4. **SAOL-uppslag:** Varje ord slås upp via `https://svenska.se/?q=ORD&activeTab=saol`
   och antalet träffar registreras. "✓" = finns i SAOL, "✗" = Saknas i SAOL.
